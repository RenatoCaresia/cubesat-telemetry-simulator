# CubeSat Telemetry Simulator

A Python-based simulation of a CubeSat telemetry system.

The project simulates a satellite generating telemetry data and
transmitting it to a ground station.

## Features

- Satellite telemetry generation
- Battery monitoring
- Temperature monitoring
- Orbital parameters
- Ground station simulation
- Packet transmission
- Packet loss simulation
- Telemetry logging
- Data visualization

## Architecture

CubeSat → Telemetry → Communication Link → Ground Station → Analysis

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- SQLite
